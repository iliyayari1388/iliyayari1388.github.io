# Iliya Yari — Personal Portfolio

A static, GitHub Pages-ready personal portfolio.

## Files
- `index.html` — content and structure
- `style.css` — visual system and responsive design
- `script.js` — interactions, animations, canvas visuals, filters, command palette, theme toggle

## Customize
Search in `index.html` for your content. In particular, update project cards and add official achievements only after verifying them.
